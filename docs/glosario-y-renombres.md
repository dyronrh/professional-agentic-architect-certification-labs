# Glosario y renombres de productos (2026)

El examen usa los **nombres nuevos**. Muchos tutoriales y respuestas en foros usan los antiguos:
apréndete esta tabla antes de hacer preguntas de práctica.

| Nombre antiguo | Nombre en el examen |
|---|---|
| Vertex AI / Vertex AI Platform | **Gemini Enterprise Agent Platform** ("Agent Platform") |
| Vertex AI Agent Engine | **Agent Runtime** |
| Agent Engine Sessions / Memory Bank | **Agent Platform Sessions** / **Agent Platform Memory Bank** |
| Agent Engine Code Execution | **Agent Platform Code Execution** |
| Vertex AI Search | **Agent Search** |
| Vertex AI Vector Search 2.0 | **Agent Retrieval** (Vector Search 1.0 sigue como *Vector Search*) |
| Vertex AI RAG Engine | **RAG Engine** |
| Vertex AI Studio | **Agent Studio** |
| Gen AI evaluation service | **Agent Platform Gen AI evaluation service** |
| Vertex AI Model Garden | **Model Garden** |
| Google Agentspace | **Gemini Enterprise** (la app para empleados) |
| Agent Designer (Gemini Enterprise) | **Workflow Builder** |
| Dialogflow CX / CCAI | **CX Agent Studio** / **Gemini Enterprise for Customer Experience** |
| NotebookLM Enterprise | **Gemini Notebook Enterprise** |

> ⚠️ **Gemini Enterprise** (app SaaS para empleados) ≠ **Gemini Enterprise Agent Platform** (plataforma para desarrolladores).

Fuente: guías comunitarias de estudio de 2026 (ver README). Verifica en
[docs.cloud.google.com](https://docs.cloud.google.com) si algún nombre cambió de nuevo.

## Siglas que debes dominar

| Sigla | Significado |
|---|---|
| ADK | Agent Development Kit (framework open source de Google para agentes) |
| MCP | Model Context Protocol (agente ↔ herramientas/datos) |
| A2A | Agent2Agent protocol (agente ↔ agente; *Agent Card*) |
| HITL | Human-in-the-loop (aprobación humana) |
| PAB | Principal Access Boundary (límite de acceso de principales) |
| VPC-SC | VPC Service Controls (perímetro anti-exfiltración) |
| PSC-I | Private Service Connect interface (salida privada desde servicios gestionados) |
| ADC | Application Default Credentials |
| WIF | Workload / Workforce Identity Federation |
| 2LO / 3LO | OAuth de dos patas (máquina a máquina) / tres patas (en nombre del usuario) |
| SDP | Sensitive Data Protection (ex DLP) |
| RRF | Reciprocal Rank Fusion (búsqueda híbrida) |
| CUD | Committed Use Discount |
